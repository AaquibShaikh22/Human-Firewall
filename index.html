About Human Firewall

🎯 Project Objective

Human Firewall is an interactive cybersecurity-awareness game designed to teach users how to recognize phishing emails, fake login pages, online scams, and social-engineering attacks — the most common threats targeting everyday people.

🛠 Technologies Used

  • HTML5 — Structure and content
  • CSS3 — Styling, animations, responsive layout
  • JavaScript (ES6+) — Game logic, scoring, interactions
  • localStorage — Save progress across sessions

🕹 How To Play

  1. Open the Dashboard and click Start Training.
  2. Select a challenge category: Phishing Emails, Fake Login Pages, or Social Engineering.
  3. Choose Learn Mode (no timer) or Timed Challenge.
  4. Read each scenario carefully and choose the safest response.
  5. Earn 100 points per correct answer and unlock badges.
  6. Review explanations to learn why answers are correct.
  7. Complete all categories to become a Human Firewall Elite.

📚 Educational Purpose

This project is built for cybersecurity awareness education. All scenarios are fictional simulations. No real credentials, OTPs, passwords, or banking information are collected or required at any point.

⚠️ Disclaimer

All email addresses, domain names, brand names, and scenarios in this game are entirely fictional and created for educational purposes only. Any resemblance to real persons, organizations, or websites is coincidental. This application does not send, receive, or store any personal data on external servers. All progress is saved locally on your own device via localStorage.
